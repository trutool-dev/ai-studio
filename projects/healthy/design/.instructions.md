### DS-06: Validar accesibilidad visual
- Archivo: `design/ACCESSIBILITY_AUDIT.md`
- Realiza auditoría WCAG AA (Web Content Accessibility Guidelines 2.1 Level AA):

  **Contraste mínimo:**
  - Texto normal: 4.5:1
  - Texto grande (18pt+): 3:1
  - Componentes gráficos (botones, iconos): 3:1
  - Audita cada pantalla con herramienta: Contrast Ratio, Stark (Figma), o manual
  - Lista colores problemáticos si los hay

  **Tamaños táctiles:**
  - Botones mínimo 44x44pt (iOS) o 48x48dp (Android Material)
  - Links y targets interactivos: mínimo 44x44pt
  - Espaciado entre botones: mínimo 8pt

  **Tipografía:**
  - Body text: mínimo 16pt (legible cómodo)
  - Small text: máximo 12pt (solo para metadatos, timestamps)
  - Line height: mínimo 1.5em para readability
  - Font weight coherente: no mezcles mucho bold/regular en mismo párrafo

  **Color:**
  - No uses color SOLO para comunicar (rojo = error, verde = éxito): añade ícono o texto
  - Modo oscuro: suficiente contraste en ambos modos
  - Daltonismo: audita rojo/verde (protanopia), azul/amarillo (tritanopia)

  **Layouts:**
  - Responsive: ¿se ve bien en 320pt (iPhone SE) y 480pt (Android pequeño)?
  - Zoom: escalable sin quebrar layout hasta 200%

  **Resultados:**
  - Tabla: [Pantalla] [Elemento] [Contraste actual] [WCAG Pass/Fail] [Fix]
  - Si algo falla: proporciona fix específico (cambiar hex de color, aumentar size, etc.)

**Éxito:** Auditoría WCAG AA completa, lista de fixes requerida, todas las pantallas ≥ AA
